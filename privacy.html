Privacy Policy - Pak RW

Pak RW hanya menyimpan data yang diperlukan untuk menjalankan fitur bot Discord.

Data yang dapat disimpan

  • ID server
  • ID channel
  • ID role
  • ID user
  • Konfigurasi fitur bot
  • Data yang dibutuhkan untuk auto role, panel, voice, reminder, dan fitur komunitas

Data yang tidak diminta

Pak RW tidak meminta password Discord, token akun, data pembayaran, atau informasi pribadi sensitif.

Penggunaan data

Data digunakan hanya untuk menjalankan fitur bot, menyimpan pengaturan server, memperbaiki bug, menjaga keamanan, dan meningkatkan stabilitas layanan.

Berbagi data

Data tidak dijual kepada pihak lain.

Penghapusan data

Pemilik server dapat meminta penghapusan data server jika bot tidak lagi digunakan.

Untuk pertanyaan atau permintaan penghapusan data, hubungi tim Pak RW.
